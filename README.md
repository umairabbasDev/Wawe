# Wawe 2.0

## Overview

**Wawe 2.0** is a personal library application designed to manage and organize PDF files efficiently. Built using modern development tools, Wawe 2.0 leverages the power of Vite for fast builds and PNPM for efficient package management.

## Features

- **PDF Collection**: Easily upload and manage your PDF files.
- **Personal Library**: Organize PDFs into categories or collections.
- **Search & Filter**: Quickly find documents using search and filter options.
- **User-Friendly Interface**: Intuitive UI for seamless interaction.

## Technologies Used

- **Vite**: A modern build tool that provides fast and optimized builds.
- **PNPM**: A fast, disk space-efficient package manager.

## Prerequisites
To run Wawe 2.0 locally, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (version 14.x or later)
- [PNPM](https://pnpm.io/)

## Installation

1. **Clone the Repository**

   ```bash
   git clone https://github.com/yourusername/wawe-2.0.git
   cd wawe-2.0
   ```

2. **Install Dependencies**
   ```bash
   pnpm install
   ```
3. **Run the Development Server**

   Start the Vite development server with:

   ```bash
   pnpm dev
   ```

   The application should now be running at [http://localhost:3000](http://localhost:3000).

## Usage

- **Upload PDF Files**: Use the upload button in the UI to add PDF files to your library.
- **Organize PDFs**: Drag and drop files into categories or collections as desired.
- **Search**: Utilize the search bar to find specific documents quickly.

## Building for Production

```bash
pnpm build
```
